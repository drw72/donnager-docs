# Contributing

## Purpose

This repository documents the configuration and administration of the
**Donnager** scientific computing server.

## Writing Standards

-   Write in Markdown.
-   Prefer step-by-step procedures.
-   Include command examples in fenced code blocks.
-   Explain destructive operations with clear warnings.
-   Keep screenshots current with Ubuntu 26.04 and JupyterLab 4.

## File Naming

-   Lowercase filenames where practical.
-   One topic per chapter.
-   Images belong in `assets/`.

## Commit Messages

Examples:

``` text
Add JupyterHub installation chapter
Update BASE-9 configuration guide
Correct Ollama GPU configuration
```

## Review Checklist

-   Commands tested
-   Links verified
-   Screenshots updated
-   Grammar checked
-   PDF builds successfully
